# 音频与字幕分析记录

素材：`downloads/BV1JA41147Qo/ruguodangshi_BV1JA41147Qo.m4a`（AAC 48 kHz 立体声，314.24 s）。
参考 MV 的音轨与独立音频逐样本对齐（互相关滞后 0 样本），所以 MV 画面时间可以直接当原曲时间用。

## 方法

1. **能量 / 低频 / 中置人声带**（`scripts/vocal.py`）：把中声道 (L+R)/2 和侧声道 (L−R)/2 分开，计算 250–3500 Hz 能量差（粗略表示人声），并计算 RMS 和 150 Hz 以下能量。图见 `energy_58-116s.png`。
2. **节拍**（`scripts/beats.py`，librosa 1.0）：八分音符间隔稳定在 0.395 s，即约 76 BPM 的四分音符；小节约 3.16 s。
3. **字幕交叉核对**（`scripts/ktv.py` + `ktv3.py`）：逐帧读取参考 MV 的 KTV 字幕区，检测蓝色擦色走到的位置，得到每句真实的开唱和结束时间，再和 LRC 对照。
4. **切点**（`scripts/cut.py`）：在 67.05–67.55 s 内搜索起点，使起点和起点+30 s 两处的 RMS 都处在低谷。

两者一致：MV 擦色比 LRC 晚 0.1–0.3 s（检测阈值和擦色起步造成）。歌词文字两边完全相同，没有冲突。
字幕出现时间取 LRC 时间（略早于开唱），消失时间取擦色结束后约 0.3 s。

## 结构观察

- 63.9–64.3 s、76.55–76.9 s 两处出现整体停顿（RMS 降到 −40 dB 左右），76.6 s 这次停顿落在试片 9.3 s。
- 84.0–84.8 s 是长音衰减，84.87 s 重新进入并一路推向副歌。
- 91.15 s 副歌下拍，低频出现规律的底鼓。
- 97.29 s 是副歌第一、二句之间的换气谷（−24 dB）。
