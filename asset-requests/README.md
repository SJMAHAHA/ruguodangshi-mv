# 素材需求（给 Codex / image2.5）

《如果当时》MV 里的人物是代码画的骨架，场景、道具和近景的手是水粉插画贴图。这里列的是需要你用 image2.5 画的贴图。
画好后放进项目根目录的 `incoming/`，文件名按下表。我（Claude）会把它们接进代码；处理过的文件移到 `incoming/done/`。

## 通用要求

- **画风**：精致的手绘水粉插画，笔触松弛，带纸张纹理，低饱和。可以参考 `refs/style_memory_photo.jpg`（片中回忆合影的画风）。
- **背景**：最好直接输出**透明背景的 PNG**。如果做不到透明，就用均匀的纯绿色 `#00FF00` 背景，不要阴影、不要渐变、不要任何其他东西，我这边抠像。
- **画布尺寸和锚点必须准确**：每张图都有固定的画布尺寸和一个锚点像素（笔尖 / 指尖）。代码是按锚点把贴图对到笔尖位置上的，锚点偏了，笔尖就写不到字上。参考图 `refs/hand_*.png` 的画布尺寸和锚点位置就是成品要求的，构图请照着它，只是把它画精致、画真实。
- **不要画投影**（手在纸上的影子由代码加，会随着抬笔、落笔变化）。
- 人物配色：`refs/charsheet_memory.png` 右边是回忆里的两个人（男生米白色外套，女生黄色风衣），肤色是温暖的浅肤色。
- 不要文字、签名、水印。
