## 1. 难点：画出来的人要会动

现在的人物是代码骨架，转头、眨眼、起身、走路、放花束都是逐帧算出来的。换成水粉画以后，每个动作都要有画好的图。全片 40 个镜头里，人物要做的动作大致分四类：

| 动作类型 | 例子 | 用什么做 |
|---|---|---|
| 几乎不动 | A1 远景、G8 背影 | 一张人物层；呼吸、轻微晃动、镜头推移由代码做 |
| 局部变化 | 眨眼、开口、视线、手指收拢、笑 | **局部重绘状态图**：同一张底图，只重画一小块（像 A3 眨眼包），蒙版外逐像素一致 |
| 头部转动、身体前倾 | A3 他转向她、B2 她凑到他耳边 | **分层**：头（连头发）、身体、手臂分开画，代码做小角度转动和位移，大角度换图 |
| 大动作 | 起身、坐下、转身、放花束、走路 | **关键张序列**：同一张画布逐张画，每秒 10–12 张（「一拍二 / 一拍三」的手绘动画节奏），代码按时间换张 |

已经画好、继续用的：写字的手（B3）、握手机的手（A5）、雾上写字的手（E2/E3）、伸手的手（D2）、C1 她的回忆脸、回忆合影。新人物的手和脸要和它们对得上。

代码继续负责：镜头运动、时间、字幕、花瓣、花束、道具、背景板、雨、光效，以及从已有人物图**派生**出来的效果：

- F3 她的铅笔草稿：从 S2 的起身、离开序列提边缘线，不另画。
- E1 墙上的影子：用走路循环剪影压暗、虚化。
- 玻璃和水洼里的倒影（A6、E3、E4、H2）：用对应镜头的人物图翻转、虚化、降低透明度。
- G7 她化作花瓣散开：在她的人物层上做溶解。

## 2. 分批

1. **第 0 批：角色设定。** 先把两个人画定，之后每一张都拿它当参考。

## 7. 通用技术规范

- **参考包**：每个镜头由 Claude 准备 `asset-requests/refs/chars/<镜头>/`，内容如下。
  - 现在片中关键时刻的帧，作构图和位置参考。
  - 去掉人物的空背景帧。
  - `spec.json`，写明：
    - 画布尺寸；
    - 锚点（坐姿是屁股和长椅座面的接触线、脚底；站姿和走路是每张两只脚的着地点；手和道具的接触点：花束花茎、手机、书）；
    - 每张图对应的时间点；
    - 光的方向和颜色。
- **交付**：`incoming/chars/<镜头>/`，文件如下。
  - 人物层 `layer-<名>.png`（RGBA，透明背景）。
  - 局部状态 `states/<部位>-<状态>.png`：和底图同尺寸，蒙版以外逐像素一致。
  - 序列 `seq/<动作>/000.png …`：同一画布，不要逐张自动裁切。
  - `manifest.json`：帧序、锚点、哪些是重复帧。
  - 可以附预览 GIF，正式使用 PNG。
- **画布和分辨率**：按镜头里人物在画面上的最大尺寸 × 镜头最大放大倍数 × 1.25。镜头会慢推 4–16%，不能放大后发虚。
- **分层**：
  - 需要转头的镜头，头（连头发）和身体分开，接缝藏在领口里。
  - 拿东西的手（花束、手机、书）单独一层，画在道具上面。
  - 手臂有大动作的镜头，手臂单独一层。
- **不画**：地面上的投影、接触阴影（代码加，会随动作变化）；花束、手机、书、耳机线（道具由代码 / 已有贴图画，手要留出握的位置）；字幕和任何文字。
- **光**：每个镜头的人物按该场景的光来画（黄昏、雨夜路灯、月夜栈桥、黎明、回忆暖光），参考包里给出空背景帧。同一个姿势出现在不同光线的镜头里，要分别画，不能只调色。
- **透明通道**：边缘干净，背景上不能残留半透明的雾。交付前用 `python3 scripts/clean-alpha.py --check` 检查：主体以外的残留像素应低于 1%。
- **一致性**：每次生成都附上第 0 批的角色设定图。序列里每一张身体的大小、颜色、笔触要一致，换张时不能「闪」。

## 9. 用户的决定（2026-10-24）

1. **流畅度**：接受每秒 10–12 张的手绘动画节奏。
2. **不精画的部分**：按建议，远处很小的人影（S4、H1、C2）、墙上的影子（E1）、铅笔草稿（F3）、倒影（A6、E3、E4、H2）从水粉人物图派生，或沿用代码。
3. **写实程度**：以 A3 试片为准。
4. **先试再铺**：先做第 0 批 + A3 + S2，接进片子看效果，再决定是否铺开。
