## 要求

- 画风和 A3 试片一致：水粉、纸纹、笔触松弛；比代码人物写实，但不要照片感。
- 光用中性的柔光，方便之后按每个镜头的场景重新打光。
- 透明背景 PNG，背景上不要残留半透明的雾（交付前用 `python3 scripts/clean-alpha.py --check` 自查）。
- 不要文字、签名、水印。图里需要标注的话，写进 `manifest.json`，不要画在图上。
