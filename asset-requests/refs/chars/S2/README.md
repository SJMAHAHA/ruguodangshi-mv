# S2 人物需求（第 1 批 · 试验镜头）

**镜头**：S2「手先松开」，全片帧 2308–2546（试片 9.63–17.57 s），雨夜，公交站长椅。
**内容**：
1. 她把手从他手下抽回，他低头看自己的手，手指慢慢收拢。
2. 她前倾、起身、站定，靠他那只手朝他抬了一下又放下，转身向右走出画面。
3. 他抬头追看，已经晚了，视线落回空位。

**镜头运动**：代码做，放大 1.30 → 1.33 倍；她起身时镜头轻轻上摇，她走后落回长椅。

下文的时间都用**试片秒**；全片帧 = 2019 + 试片秒 × 30。

## 画布和对位

- 交付画布 **3840×2160**（参考图的 2 倍）。所有图同一画布、同一位置，**不要逐张裁切**。
- 坐标按 2 倍算，误差 ±20 px：

| 位置 | 坐标 |
|---|---|
| 长椅座面（屁股落点） | y ≈ 1530 |
| 地面（鞋底） | y ≈ 2080，两人全程都踩在这条线上 |
| 他 | 身体中线 x ≈ 1600，头部中心约 (1600, 580) |
| 她（坐） | 身体中线 x ≈ 2140，头部中心约 (2140, 600) |
| 她（站直） | 头部中心约 (2140, 200)，脚不离开原地 |

- 长椅、花束、雨由代码画，**人物层里不画**。长椅在人物后面，人物的腿在座面前面。

## 她：一套全身序列

每张都是完整的全身人物，包括两只手。帧序和时间写进 `manifest.json`。

| 编号 | 时间（试片秒） | 姿势 | 对照 |
|---|---|---|---|
| `her/00` | 9.63–9.86 | 坐着，身体微微侧向他。靠他那只手（她的左手，画面左侧）放在两人之间的座面上，被他的手压着；另一只手放在腿上 | `pose_2310_start` |
| `her/01`–`04` | 9.86 / 10.1 / 10.4 / 10.8 | 抽手：手从他手下滑出、微微抬起、收回放到自己腿上；头从看他转为看向前方偏下，肩膀先轻轻一耸 | `pose_2315`–`2343` |
| `her/05`–`07` | 13.15 / 13.32 / 13.5 | 前倾：上身前倾，重心移到脚上，两手撑在大腿上 | `pose_2408`–`2424` |
| `her/08`–`13` | 13.65 / 13.8 / 13.95 / 14.1 / 14.25 / 14.4 | 起身：撑着大腿站起来，上身最后才挺直。脚原地不动 | `pose_2433`–`2451` |
| `her/14`–`16` | 14.55 / 14.75 / 14.95 | 犹豫：站着，靠他那只手朝他抬起一点（前臂向前伸），又放下；脸朝向他一点但没看他 | `pose_2459` |
| `her/17`–`19` | 15.03 / 15.12 / 15.2 | 转身：从正面转成正侧面朝画面右边 | `pose_2467`–`2475` |
| `her/walk/00`–`11` | 15.2 起循环 | 正侧面朝右的走路循环（两步一周期，12 张），**原地走**：代码负责把她往右移、走出画面 | `pose_2484`–`2508` |

走路循环的要求：

- 一步的步长在画布上约 **413 px**；一个周期两步，每步 6 张，着地脚每张向后移约 69 px，这样代码平移时脚不会打滑。
- 两只脚轮流着地，着地的鞋底都在 y ≈ 2080。
- 风衣下摆随步子摆动，头发随步伐轻甩。
- `manifest.json` 里标出每张哪只脚着地、着地脚的 x。

- **图层顺序**：她的序列 → 他的身体 → 他的头 → 他的手。他的手在最上面，开始时盖住她的手。
- 所有头部图的脖子底端和领口对齐在同一位置，换张时头不能跳。
- 手部状态图和身体对齐：手腕接缝藏在袖口里。

## 光

- 雨夜。右上方的路灯（参考图里 x ≈ 1460、y ≈ 300，按 2 倍是 (2920, 600)）是主光，暖白色，给人物画面右侧一道轮廓光。
- 其余是冷的墨蓝环境光。
- 衣服略带潮湿感，但不要画雨滴。

## 不要画

背景、长椅、花束、雨、字幕、地面投影。透明背景 PNG，背景上不要残留半透明的雾，交付前用 `python3 scripts/clean-alpha.py --check` 自查。
