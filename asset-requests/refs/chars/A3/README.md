# A3 人物需求（第 1 批 · 试验镜头）

**镜头**：A3，全片 13.05–19.0 s（帧 392–570），黄昏，雨还没下。
**内容**：他的近景，她在画面右边。他转向她，像要开口，又停住，最后低下头。她一直低头看手机。
**镜头运动**：代码做，放大 2.0 → 2.06 倍，缓慢右移。

## 参考图（本目录）

| 文件 | 内容 |
|---|---|
| `bg_empty.png` | 空背景（没有人）。**画布构图就是这张**：1920×1080，镜头 `{x: 910, y: 330, scale: 1.95}`，比正片取景略宽一点，留余量 |
| `pose_<帧>_<名>.jpg` | 同一画布上，现在的代码人物在各时刻的位置和姿势。只用来对位置，画法以 A3 试片为准 |
| `shot_<帧>_<名>.jpg` | 正片里这一帧实际看到的画面（取景略紧） |
| `../model/identity_present.png` | A3 试片：两个人的脸、发型、衣服、画法以它为准 |
| `../model/proportions.png` | 身材比例 |

## 画布和对位

- 交付画布 **3840×2160**，即参考图的 2 倍。所有图层同一画布、同一位置，**不要逐张裁切**。
- 位置以 `pose_*.jpg` 为准（坐标按 2 倍算），误差 ±20 px：
  - 他：头部中心约 (1540, 560)，肩线约 y 980。
  - 她：头部中心约 (2700, 640)，肩线约 y 960；拿手机的手在画布下沿附近，约 (2680, 2080)。
- 构图和 A3 试片相近，可以直接在试片的基础上重画对位。
