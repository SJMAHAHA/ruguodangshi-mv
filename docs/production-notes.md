# 制作说明

第一部分（1–7 节）是 30 秒试片，第二部分（8–15 节）是全曲完整版。

## 1. 原曲截取

| | |
|---|---|
| 原曲区间 | **01:07.290 — 01:37.290**（48 kHz 样本 3,229,920 — 4,669,920） |
| 试片区间 | 00:00.000 — 00:30.000（900 帧 @ 30 fps） |
| 对应关系 | 试片时间 = 原曲时间 − 67.290 s；试片第 n 帧 = 原曲 67.290 + n/30 s |
| 歌词 | 视线要模糊了 / 此时感觉到你的重要 / 爱走了 心走了 / 你说你要走了 / 我为你唱最后的古谣 / 红雨瓢泼泛起了回忆怎么潜 |
| 处理 | 原速、原调、原编曲；首 20 ms 淡入、末 0.38 s 淡出，只为避免爆音 |

**为什么是这 30 秒**：起点 67.29 s 和终点 97.29 s 都落在句与句之间的能量低谷（−28 dB / −24 dB），所以两头都不切在字上。区间里有 6 句完整歌词：分手段（爱走了 / 你说你要走了），76.6 s 处全曲停顿的一拍，以及 91.15 s 副歌下拍之后的完整第一句。
对照方案 01:10.4–01:40.4 会停在「你美目如当年｜流转我心间」中间，那里伴奏没有换气点。
歌词时间先用 LRC，再用参考 MV 的 KTV 字幕逐帧擦色位置交叉核对，两者一致（详见 `analysis/audio-analysis.md`）。

## 3. 主要设计选择

- **把公交站长椅作为两个人共用的位置**：她离开后，长椅另一半一直空着。到了副歌，这张长椅原样出现在月下栈桥上，站牌立在渡口入口，现实里的「站台」就延续成了古典意象的「渡口」。
- **现实与回忆用两种材质区分**：现实是墨蓝 / 灰绿 / 冷纸灰，石墨线，带铅笔抖动的 SVG；回忆是暖纸色、棕褐铅笔线的半透明描图纸，最后的回忆轮廓用 Canvas 绘制并擦除。
- **纸层只在有情绪理由时出现**：S3 纸层对齐，是「她好像还在」；纸层错开，是「位置已经对不上」。S5 用橡皮擦去回忆，但铅笔印擦不干净，表现「人离开以后位置还在」。
- **暗红只给花**：花束、花瓣（「红雨」）和最后落在空位上的一片花瓣；回忆里她怀里抱的就是同一束花。
- **动作先后**：每次都是她先动、他后反应（抽手 → 看手；起身 → 抬头），中间留出停顿。她起身时头部出画，镜头停在长椅和他身上。
- **字幕**：思源宋体单行、暖纸色、下方居中；时间取自实测（LRC + KTV 擦色核对）；所有镜头都检查过不压脸、手和花束。

## 4. 参考片：实际呈现与本片解释

抽帧核对过的参考片内容：灰天旧瓦房街巷、倒垂的郁金香束、相框里的合影（约 0:59 起合影里只剩男生）、夜里虚化的列车车窗（**没有明确雨痕**）、两人在暗处的近景、满月草地与远处城市灯、男子脸叠在夜空、结尾花束落地。
本片的雨夜、公交站、描图纸、渡口、长椅空位都是新的创作解释，没有加入死亡、车祸或第三者。

## 5. 技术

- Remotion 4.0.531（版本写死，保留 lock 文件）。全片 5 个 `<Sequence>`，时间集中在 `src/config/timeline.ts`。
- SVG：角色骨架（正面坐/起身的圆柱投影转身、侧面步行、背面）、旧街、站台、长椅、花束、渡口场景。
- Canvas 2D：雨丝、玻璃水珠与下滑水痕、积水涟漪、花瓣轨迹（解析函数）、回忆轮廓的绘制与橡皮擦除。
- 静态纹理：`scripts/make-textures.py` 用固定种子生成纸纹，乘法叠加在整片上，不随镜头运动。
- 检查流程：角色设定页 → 各镜头关键帧 → 960×540 带音轨测试片 → 切点前后帧 → 1080p 成片抽帧与音频核对。
- 成片核对：与原曲切片做互相关，音频滞后 0 样本；逐秒 RMS 没有意外静音；blackdetect 没有黑帧；视频 900 帧。

## 6. 检查中发现并已修正的问题

- 第一版人物肩膀方正、手臂像管子，脸上有一条硬阴影线。改为斜肩、开口袖筒和沿轮廓收尖的阴影。
- 双手在长椅上「够不着」时手臂会被拉长。按臂长重新排了两人的距离（中心距 296 px）。
- 起身后风衣像一根柱子，侧身走路时步幅过大、腿画在风衣前面。改了腰身与下摆、步幅和图层顺序，转身时先水平收窄再换成侧面画法。
- 车灯扫光是一块硬边梯形。改成柔边光晕。
- 回忆纸层太不透明，盖住了现在的他，看不出「重合」。降低了纸和人物的透明度，散去过程加长。
- 副歌开头字幕压在栈桥上的人物身上。调整了起始镜头，让长椅在字幕出现时还在画外，下摇后才进入。
- S5 橡皮擦留下百叶窗一样的条纹。笔触改为相互重叠，擦完后清干净，只保留淡铅笔印。
- S3 字幕压在暖色纸层上读不清。字幕下加了一层很淡的墨色晕底和更强的描边阴影。
- 最后那片落在空位上的花瓣太小、而且侧着看不见。放大后让它平躺着落定。
- 第一次 1080p 直出是全范围的 `yuvj420p`，AAC 补齐帧让容器显示 30.016 s。改为 PNG 帧渲染（标准范围 yuv420p、BT.709），再用 `scripts/finalize.sh` 以原曲切片重新封装音轨，视频、音频、容器都严格 30.000 s。

## 7. 仍需改进

- **人物表演还偏「纸偶」**：骨架以正面为主，转身靠圆柱投影近似。手指只有收拢一个参数，侧面步行也比较简单。正式版应补充 3/4 侧面的关键姿势，并加入手指、衣褶的二次动作。
- **铅笔质感偏弱**：现在主要靠位移滤镜和纸纹。可以加一层随机断续的线、轻微线宽变化，或者手绘的排线阴影。
- **S4 远景人物很小**：主要靠剪影和构图交代。若要强调人物，可以加一个推近镜头，或者把这一段延长到下一句歌词。
- **起身那一拍**：她的上半身出画是有意设计，但风衣站姿只露出半身，仍略显生硬。可以改成镜头轻微上摇，跟住她犹豫的那一下视线。
- 渲染：1080p 在 2 核环境下约 30 分钟，主要耗在 SVG 滤镜和全屏 Canvas 上。正式版可以把静态背景预渲染成图片。

## 10. 设计选择（完整版新增）

- **同一个位置，三种时段**：公交站长椅出现在黄昏、雨夜、黎明，月下渡口的长椅是它的延续。每一次她都坐在右边，最后右边只剩花束。
- **回忆有固定的材质**：暖纸色、棕褐铅笔线；夜里出现时在已画像素上压一层很淡的墨蓝（G6/G7），黎明时更淡（J2/J3），避免暖色跳出画面。
- **呼应的转场**：路灯光晕 ↔ 月亮（F4→G1，与试片 S3→S4 同一手法，切点两侧用同一个泛光函数 `Bloom`）；湖面 ↔ 公交站的积水（H2，积水里是上下翻转的整幅公交站）；最后整幅画面用 Sobel 边缘滤镜退回纸上的铅笔稿，再退成白纸（K2）。
- **字的去留**：她在雾玻璃上写「执子之手」，他接「与子偕老」（E2/E3）；多年后他呵一口气，旧字在雾里重新显出来（E4）；雨水一道道冲开雾，把字带走（F1）。
- **放下而不是失去**：G7 她笑了一下才化作花瓣；J2 纸层最后一次完全对齐，他也笑了；J3 他自己把花束放到她的位置上，纸层这时才散去，然后他起身离开。没有死亡、车祸或第三者。
- **暗红只给花**：花束、花瓣、河灯光里的花瓣带。河灯、船灯、窗灯用柔金。

## 11. 参考片与本片的解释（完整版）

参考片里实际出现、本片借用的：灰天的旧瓦房街巷（→ 旧街、卷帘门）、相框里的合影后来只剩男生（→ A5/A6 手机锁屏合影里她慢慢淡去）、倒垂的花束（→ D1 他倒提着花束走过旧街）、满月草地与远处城市灯光（→ 月下渡口与对岸城市）、结尾花束落地（→ 试片 S5）。
本片自己的解释：公交站长椅这个「位置」、雾玻璃上的字、河灯上的回忆画、乌篷船、黎明把花束留在座位上。用到的古典文字：「人生若只如初见」（纳兰性德）、「执子之手，与子偕老」（《诗经·邶风·击鼓》）、杜牧《赤壁》（对应歌词里的曹操与小乔）。

## 12. 技术（完整版新增）

- 时间轴：`src/full/timeline.ts` 以原曲秒为单位，41 个镜头各是一个 `<Sequence>`；镜头内部用 `useSongT()` 直接拿原曲秒，所以动作时间点可以直接对照歌词表。
- 新的绘制：可横向跟拍的旧街长卷（D1）、晴天墙面与人物影子（E1）、雾玻璃（SVG 遮罩：雾 − 字 − 水流；呵气用径向渐变遮罩只显出一片雾）、玻璃里的倒影（镜像的半身像，胸口以下渐隐）、河灯（纸面上的回忆小画、烛光闪烁、水中倒影）、乌篷船剪影与转身（水平压缩后翻转）。
- 「化作花瓣」：把她画到离屏画布上，按打乱的格子从外侧往里擦除，读一次像素判断格子里是不是她，是的话在原位放出一片花瓣，轨迹是时间的解析函数。每帧整体重画，与渲染顺序无关。
- 尾声铅笔稿：CSS `filter: url(#k2sketch)` 引用 SVG 滤镜，灰度 → 四个方向 Sobel 求边缘 → 反相成石墨线 + 很淡的明暗 → 乘在纸色上。
- 渲染：每段 200 帧左右写成独立 MP4（同一组编码参数），可中断续跑、可在多台机器上分工；`scripts/finalize-full.sh` 检查首尾相接、总帧数后无损拼接，再用原曲 WAV 封装 AAC。

## 13. 检查中发现并已修正的问题（完整版）

- 回忆里的白天整层加滤镜会把人物洗白。改为只给背景调色，人物用回忆配色本身（`MAN_MEM` / `WOMAN_MEM`）。
- 花束放在她腿上时被她的身体挡住；他抱花束时又被他的身体挡住。花束加了图层位置参数（在她前面 / 在他前面）。
- 握铅笔的手和伸向回忆纸的手像连指手套。重画成分开的手指。
- Chrome 里 CSS mask 引用 SVG mask 对 HTML 不起作用，B5 的「雨水浸透回忆纸」改成湿痕色块 + 和 S1 底画的交叉淡化。
- C1 水中倒影的横条之间有缝。改成 45 条整数高度、`crispEdges`。
- 容器里的无头 Chrome 解不了 m4a，预览会退回 `<Html5Audio>`。改为渲染前从原曲解码出 WAV。
- E1 墙上剥落露砖的色块像飘着的橙色补丁。缩小、降低不透明度。
- E3 玻璃里的倒影一开始用「滤色」叠在浅色雾上几乎看不见，改成正常叠加后又像贴纸。改成镜像的半身像，胸口以下渐隐、轻微模糊。
- F1 冲刷雾气的水流太宽太黑，像墨汁；玻璃上的水珠像雪花。水流改细、数量加多；水珠改大、减少数量，并由路灯方向照亮。
- G2 前景河灯压住字幕、他的头被画面上缘切掉。重新取景，河灯的水线整体上移。
- G6/G7 夜里回忆的暖黄色太跳。在已画像素上压一层很淡的墨蓝。
- G7 化作花瓣时纸上露出一格一格的圆洞。擦除位置、大小、方向全部打乱，纸本身整体淡出。
- H2 湖面近景像一片雾；水洼铺满画面，看不出是积水。湖面改成横向明暗带 + 一列碎光；水洼缩小，四周露出湿柏油。
- J4 从正面站姿换成侧面行走时人突然变高。侧面画法按头顶高度缩放（0.943）对齐。
- K2 铅笔稿线条是纯黑，像描边漫画。线条最深只到石墨灰，玻璃上的水珠减少，避免变成墨点。

# 第三轮：人物质感、剩下的 SVG 场景、近景的手（2026-10-22）

## 21. 改了什么

- **人物的水粉描法**：人物不再描统一的石墨线。有填色的形状描「这块颜色加深」的线（深蓝大衣配深蓝线、皮肤配暖棕线），外面再加一道宽而淡的同色晕，模仿水彩干时颜料往色块边缘聚的效果；五官、衣褶这类单独的线条保持深色，表情照样清楚。只对人物开启（`Shapes` 的 `paint`），道具和场景不变。
- **D1、D2、E1 的背景板**：D1 旧街长卷一次生成（4600×580 世界单位，宽高比 7.9），D2 卷帘门特写、E1 晴天老墙各一张。都照原来的 SVG 构图重绘，所以盆栽、自行车、海报、尽头的卷帘门、窗、门、门牌都在原位。树影、人影、脚步涟漪、前景路灯杆仍由代码画。
- **近景里的手**：B3 两人握铅笔写字、E2/E3 手指在雾上写字、D2 伸手去碰回忆纸、A5/A6 托着手机的手，都换成绿底抠像的水粉贴图。手在镜头里只做平移和旋转，贴图与原来的 SVG 手共用同一个原点（笔尖 / 指尖），动作代码不用改。握手机的手连同手机边框一起画，屏幕抠空，盖在 `<Phone>` 上面：锁屏画面从屏幕里透出来，拇指和指尖压在手机前面；A5 拇指摩挲屏幕用两张贴图（拇指在下 / 往上滑一点）交叉淡化。原来的「屏幕光照亮手指」全矩形滤色层去掉了（水粉手本身画了冷光，留着会在手机周围显出一圈发白的矩形）。
- **B5 雨点浸透回忆纸**：原来是不透明的深青色圆斑不断扩大，像泼墨。改成回忆层用 `mask-image`（内联 SVG）挖出不规则的软边湿痕，湿痕里留 12% 的纸，透出下面垫着的 S1 雨夜；每块湿痕外圈一道棕褐色的颜料晕边，雨点落下的瞬间有一个小亮点溅开。回忆里的两个人和雨夜里的两个人坐在同一张长椅的同一个位置，湿痕扩开时就是一次叠化。遮罩每帧解码完成后才出帧。
- **河灯的小画**：耳机线、被画了胡子的古代将军、长椅上靠肩的两人、月下小船，四幅白纸上的铅笔淡彩，`--white` 把白纸转成透明，透出灯罩的暖光。「执子之手」仍用手写字体。

- **K2 尾声的铅笔稿**：原来用 SVG 边缘检测滤镜（四个方向的卷积）对整个合成画面实时计算，单帧要 25 s 以上，两个进程同时渲染时超过两分钟的时限。改成让 Seedream 照着 K2 第一帧（彩色）画一张真正的铅笔素描，按这一帧镜头看到的世界范围贴回去（之后镜头只是缓推，范围都在里面），再和彩色画面交叉淡化。素描和彩色画面叠在一起没有错位；全画面只有铅笔灰，花束里的玫瑰留一点淡红。单帧降到约 1 s。

- **写字的动作**：`src/lib/writing.ts`。每个字拆成 3–6 笔，按先上后下的笔顺写，写完一笔抬笔移到下一笔；字也按笔顺从上往下显出来，笔尖总在显字的前沿。抬笔时手微微变大、离开纸面，纸上的影子拉开变淡；手腕绕画面外的肘部转动。写之前手从画面外伸进来，写完收回去，换手时一只收一只伸（原来是在几个停放位置之间瞬移）。B4 在古人像上画胡子和眼镜：原来笔尖在胡子右边一百多像素外晃，而且胡子和眼镜同时在画；现在笔尖严格沿着曲线走，画完胡子抬笔再画两个眼镜圈。
- **雾上写字（E2、E3）**：指尖用同一套笔顺；去掉了套在水粉手上的 `pencil-soft` 位移滤镜（会把手指扭曲）；他的手不再镜像（原来变成了左手，被画面下沿一裁还像不雅手势）。
- **B2 的诗句**：原来飘到他耳边后往左上散开，正好扫过他的脸；改成从两人头顶之间往上散开，早一点淡出。
- **二次运动**：头发随风轻摆（发根不动、发梢摆得多；公交站棚下风小，栈桥上风大），女主走路时后发随步伐甩动；吸气时肩膀微微抬起。

- **骨架里的手**：原来是一团「连指手套」（圆角色块加三条短线）。改成手背靠手腕窄、指节处宽，四根手指分开（中指最长、小指最短、略微张开），蜷起时变短变圆；拇指在靠身体中线的一侧斜着收进来；背光一侧有阴影，指节一排小高光，手指伸直时露出淡淡的指甲。

## 27. 接入第三、四批时发现并修正的问题

- **D1 他飘在人行道上方**：走路骨架的鞋底在 `y = -19.6`（局部 -35.6 × 0.55），而新长卷的墙根在世界 y = 0、路沿在 y ≈ +11。人整体下移 25（`WALK_Y`），鞋底落在墙根和路沿之间那条窄人行道上；接触影子、落脚涟漪、倒提的花束跟着下移。
- **D1→D2 卷帘门对不上**：D2 原来的 Seedream 背景板是青绿色的细板条（一块板条约 36px，回忆纸有 14 块板条宽，按人的身高算纸有一米多宽），D1 新长卷里是灰蓝色的宽板条。D2 改成直接把 `d1_strip-b.jpg` 里同一扇卷帘门放大 1.55 倍铺满画面（门框以内、墙根以上），板条约 82px，纸约 6 块板条宽（四十多厘米）；颜色、锈迹、斜着的光影都和 D1 最后几秒一致。纸被吹走后留下的印子改成略浅（被纸挡住的地方没那么脏）。
- **D2 的纸和手太亮、像贴上去的**：两者各加一层夜色（略压暗、偏冷）和投在门上的软影；纸被风吹离门面时影子拉远、变淡。SVG 滤镜默认在线性色彩空间里算，压暗和影子都比数值弱很多，改成 `color-interpolation-filters="sRGB"`。
- **伸手贴图的背景雾**：`hand_reach-him.png`（Seedream 时期抠的）背景上残留大片 alpha 5–60 的雾，占画布 43%，盖在门上是一块发灰发绿的方形，影子也跟着变成一大片。新增 `scripts/clean-alpha.py`：主体（alpha ≥ 160）开运算去噪后外扩几像素、羽化，乘回原 alpha，主体边缘的过渡保留、外面的雾清零。`--check` 可以统计所有贴图：其他手和道具的残留都在 1% 以下；灯笼的「残留」是有意画的光晕，不动。原图备份在 `out/plates_src/hand_reach-him.hazy.png`。
