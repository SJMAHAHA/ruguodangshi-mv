依据（详见 `analysis/audio-analysis.md`）：

- 起点 67.29 s 是「天灰了 雨坠了」与「视线要模糊了」之间的能量谷（−28 dB，低频同时回落）；人声在 67.5 s 后进入。

- 所以试片含 6 个完整歌词句，没有半句；分手段（爱走了 / 你说你要走了）和副歌入口（91.15 s）都在里面。
- 备选 01:10.4–01:40.4 会停在「你美目如当年｜流转我心间」中间，伴奏无换气点，故放弃。

## 4. 情绪结构

1. **还在一起，但已经不在一起**（0–9.6 s）：两人并排坐着，他看她，她只看来车的方向。停顿时画面一起静止。
2. **离开开始**（9.6–17.6 s）：她先抽回手，他过一会儿才低头看手。她起身离开，他抬头时她已经走出画面。
3. **回忆与现实错位**（17.6–23.9 s）：暖色描图纸带回过去，两人的位置对上，随后纸层慢慢偏开。
4. **副歌展开**（23.9–27.0 s）：空间突然打开，暗红花瓣大量落下，现实街景延续成月下渡口。
5. **位置还在**（27.0–30.0 s）：她的回忆轮廓被擦去，长椅另一半只剩花束、一片花瓣和一道擦不干净的铅笔印。

## 5. 美术规范（摘要）

- 现实层：墨蓝 #243241、灰绿 #697469、冷纸灰 #B4B8B2；回忆层：暖纸 #DDD3BD、柔金 #C5A275、淡肤色 #E3C3A8；暗红 #A75458 只用于花、花瓣和最后的空位。
- 线：石墨灰 #2B2F35，约 2.5–3.5 px（1080p），以固定种子的位移滤镜做轻微手绘抖动（随物体移动，不逐帧跳）。
- 填色：哑光平涂+柔和渐变，整片叠一张静态纸纹（固定种子生成）。
- 回忆层：暖纸底、棕褐铅笔线、低饱和水粉，透明度 0.6–0.85，边缘有纸张轮廓。
- 人物：男主（短黑发、乱刘海、墨蓝大衣、灰毛衣领），女主（及肩黑发、侧分刘海、冷灰风衣、灰绿毛衣）。回忆里换成浅色衣服，发型与五官不变。
- 字幕：思源宋体（Noto Serif SC）子集，38 px，暖纸色 90%，单行，画面下方居中，自动避让手和花束。
